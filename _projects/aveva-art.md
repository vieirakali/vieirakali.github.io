ART (Automatic Recognition and Tagging) was a project to automate the tagging of industrial assets (valves, tanks, pumps, and so on) in 3D point cloud environments. The process supports the creation of real-time digital twins for operations, maintenance, and engineering.

As the Product Designer on this highly technical initiative, I was responsible for making the AI-powered tagging process intuitive, efficient, and usable within AVEVA’s point cloud management environment.

*Due to the confidential nature of the project, only a few representative wireframes can be shown.*

## Design challenges

- Designing over 3D point cloud data: dense, unstructured, and visually complex.
- Balancing automation (AI) with human control and validation.
- Supporting precision-critical users (engineers, planners) in high-stakes environments.
- Making the UI feel responsive, searchable, and scalable for large industrial models.

## Design process

### Discovery and technical immersion

- Met with engineering stakeholders to understand current manual tagging pain points.
- Explored AVEVA’s existing point cloud software and plugin architecture.
- Documented technical constraints around AI detection, scan density, and tag metadata.

### User and workflow research

- Interviewed and mapped out workflows for asset engineers and maintenance planners.
- Identified core user tasks: review, approve, correct, search, bulk edit tags.
- Defined friction points in manual workflows: cluttered UIs, low trust in AI.

### Task mapping and UX goals

- Designed flows for key tasks (tag review, filtering, metadata linking).
- Prioritized clarity, spatial context, and minimal cognitive load.

### Wireframing and interaction design

- Created the UI for the point cloud viewer.
- Built flows for reviewing and correcting AI-suggested tags.
- Considered scenarios like overlapping tags, visual clutter, and false positives.
